# Reverse Learning

我的逆向工程学习记录与 CTF Reverse 复盘仓库。

## 学习目标

- 提升静态分析能力
- 提升动态调试能力
- 理解 x86/x64 汇编与 Windows 底层机制
- 通过复盘积累 CTF Reverse 解题方法

## 学习档案

- [笔记总索引](notes/README.md)
- [Reverse 笔记模板](templates/reverse-note-template.md)

每次学习记录优先保留分析过程，而不是只保存最终答案。内容通常包括：

1. 原始问题与已知条件
2. 静态分析思路与 Ghidra 操作
3. 关键汇编指令、调用约定和数据流
4. Windows 底层机制
5. x64dbg 动态验证过程
6. 阶段性结论、易错点与后续练习

## 发布原则

- 不公开仍在进行中的比赛 Flag 或受限题目附件。
- 上传前检查账号、路径、Token、Cookie 等敏感信息。
- 无法确认公开范围时，只记录通用方法和脱敏后的分析过程。
- 笔记中的结论应能由静态证据或动态调试结果支持。
